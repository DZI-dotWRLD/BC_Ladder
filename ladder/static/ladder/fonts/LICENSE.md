# Bundled fonts

Self-hosted because the Content Security Policy only allows same-origin fonts.
Both families are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org).

- `inter-var.woff2`: Inter (variable weight, Latin subset) by Rasmus Andersson.
- `cormorant-var.woff2`, `cormorant-var-italic.woff2`: Cormorant Garamond (variable weight, Latin subset) by Christian Thalmann.

Subsets were downloaded from Fontsource.
